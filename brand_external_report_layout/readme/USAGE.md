To use this module, you need to:

1.  Go to Settings \> Users & Companies \> Brands
2.  Add a new brand or select an existing one
3.  Enter brand information and click **Configure Document Layout**.
4.  Select the layout, table design, font, logo, and colors, then save.
5.  Go to any branded object and print the PDF report. It includes the
    information of the brand.

Odoo 20 layouts and table designs can be selected independently for each
brand. Documents whose brand has no configured layout use the company layout.
