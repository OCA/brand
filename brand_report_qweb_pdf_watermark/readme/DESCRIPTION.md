This module adds brand specific watermarks (backgrounds) to PDF reports.

It does not add any reports by itself. It provides a "Use Brand Watermark"
check box on reports and a PDF watermark field on brands. Use it in
combination with a module that adds a brand to a model, such as
`account_brand` or `sale_brand`.

When the box is checked and the brand of the printed record has a watermark,
the watermark is added to the PDF.
